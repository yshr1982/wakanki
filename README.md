# 和漢記（Chrome 拡張） v0.5.0

**和漢記**は、中国語のウェブページを日本人が読みやすくする Chrome 拡張です。
簡体字・繁体字を**日本の漢字（新字体）と日本語の字形**で表示し、必要なら**返り点・送り仮名**で日本語の語順を示します。

> このリポジトリは公開用です。コードは開発用リポジトリから自動で反映されます。不具合の報告や要望は Issue でお知らせください。

## できること

| 機能 | 内容 | 例 |
|---|---|---|
| 漢字変換 | 簡体字・繁体字・台湾/香港の字体を、日本の漢字にする | 这是我们的学校 → 這是我們的学校 / 关系 → 関係 / 启动 → 啓動 |
| 日本語の字形で表示 | 「化」「術」など文字コードが同じでも中国の字形で描かれる字を、日本語のフォントで描く | 中国語フォント指定のページでも日本の字形に |
| 返り点（試験的） | 現代中国語の文に、日本語で読む順を示すレ点・一二点・上下点を付ける | 我想去北京看朋友 → 我想<sub>二</sub>去<sub>レ</sub>北京看<sub>一レ</sub>朋友 |
| 送り仮名 | 返り点に合わせて、ヲ・ニ・ト・ヨリ などの助詞を小さく付ける | 我想<sub>二</sub>去<sub>レ</sub>北京<sup>ニ</sup>看<sub>一レ</sub>朋友<sup>ヲ</sup> |
| ひらがな化 | 的→の、和→と、了→た など、機能語の漢字をひらがなにする（返り点とは同時に使えません） | 我的书 → 我の書 |

- 入力欄・テキストエリア・コード・編集できる要素は変更しません。
- 後から読み込まれる内容（無限スクロールなど）も変換します。
- 設定は再読み込みなしで反映され、OFF にすると元の文字に戻ります。
- 通信は一切しません。ページの文章を外部に送ることもありません。権限は `storage`（設定の保存）と `activeTab`（ポップアップで今のサイト名を表示するため）だけです。

## インストール

Chrome ウェブストアには未公開のため、「パッケージ化されていない拡張機能」として読み込みます。

1. このリポジトリをダウンロードする
   - GitHub の **Code → Download ZIP** でダウンロードして展開する、または
   - `git clone https://github.com/yshr1982/wakanki.git`
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパー モード** を ON にする
4. **パッケージ化されていない拡張機能を読み込む** を押し、展開したフォルダ（`manifest.json` がある場所）を選ぶ
5. ツールバーのパズルのアイコンから **和漢記**（「漢」のアイコン）をピン留めする

ローカルの HTML ファイル（`file://`）でも使うときは、拡張機能の詳細で **ファイルの URL へのアクセスを許可する** を ON にします。

### 更新するとき

新しい版をダウンロード（または `git pull`）してから、`chrome://extensions` で和漢記の **再読み込み**（↻）を押します。

## 使い方

ツールバーの「漢」アイコンを押すと、設定が開きます。

| 設定 | 既定 | 内容 |
|---|---|---|
| 漢字変換 | ON | 全体の ON/OFF |
| ひらがな化 | OFF | 機能語のかな化（返り点が ON の間は使えません） |
| 返り点（試験的） | OFF | レ点・一二点を付ける |
| 送り仮名 | ON | 返り点に合わせて助詞を付ける（返り点が ON のときだけ） |
| 日本語の字形で表示 | ON | 日本語のフォントで描く |
| このサイトでは使わない | — | 今のサイトだけ無効にする |
| このタブを元に戻す | — | 今のタブだけ一時的に元に戻す（再読み込みで再び変換） |

## 制限

- 字の置き換えなので、中国語の語彙・文法は日本語になりません（翻訳ではありません）。
- 返り点・送り仮名は、単語分割と品詞による規則で付けています。よくある文の型には付きますが、長い文・複文・成語では誤りや付け漏れがあります。送り仮名は助詞だけで、活用語尾は付けません。
- 日本語の字形で表示するには、PC に日本語フォント（ヒラギノ、游ゴシック、メイリオ、Noto Sans CJK JP など）が必要です。
